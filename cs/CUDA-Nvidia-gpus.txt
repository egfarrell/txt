### Gensis mount volume
    - Genesis `mount volume` https://support.genesiscloud.com/support/solutions/articles/47001259016-how-to-format-and-mount-block-storage-volume
        lsblk -f
        sudo mkfs.ext4 /dev/vdb         # format volume
        lsblk -f
        sudo mkdir /mnt/ARIEL_DATA
        sudo mount -o defaults /dev/vdb /mnt/ARIEL_DATA
        df -h
        ls -ld /mnt/ARIEL_DATA          # Check ownership
        sudo chmod 777 /mnt/ARIEL_DATA  # change permissions
        # ensure volume is auto-mounted
            sudo vim /etc/fstab
        # add this line
            /dev/vdb    /mnt/ARIEL_DATA   ext4   defaults,nofail   0   2

### Cloud providers
    - As one of the first major cloud providers to provide GPU
      cloud service, Amazon offers various GPUs in its `P3` and
      `G4` EC2 instances.
    - The P3 instance offers the Tesla V100 GPU (one of the most
      popular NVIDIA GPU provided by many cloud providers), which
      has 16 GB and a 32 GB variant of VRAM per GPU.

### List GPU's
    - SIMPLE WAY
        lspci | grep -i nvidia

    - SINGLE GPU CARD
        > lspci  -v -s  $(lspci | grep ' VGA ' | cut -d" " -f 1) <--- doesnt work
        lspci  -v $(lspci | grep ' VGA ' | cut -d" " -f 1)
        - Inner command finds device ID, equivalent to:
            - lspci  -v -s  81:00.0

    - MULTIPLE GPU-CARDS
        lspci | grep ' VGA ' | cut -d" " -f 1 | xargs -i lspci -v -s {}


### Install CUDA
    - Download Nvidia drivers
        - See: https://developer.nvidia.com/cuda-toolkit-archive

        - Example:
            ai build-essential
            CUDA 11.1
                wget https://developer.download.nvidia.com/compute/cuda/11.1.1/local_installers/cuda_11.1.1_455.32.00_linux.run
                sudo sh cuda_11.1.1_455.32.00_linux.run

            CUDA 11.4 (Rakija)
                wget https://developer.download.nvidia.com/compute/cuda/11.4.1/local_installers/cuda_11.4.1_470.57.02_linux.run 
                - (note: I wanted to add '--toolkit' because I don't want to re-install the NVIDIA drivers, but this didn't work)
                sudo sh cuda_11.4.1_470.57.02_linux.run --toolkit 


        - NOTE: install sometimes _fails_. Check logs:
            cat /var/log/cuda-installer.log
            cat /var/log/nvidia-installer.log
            - disable nouveau
                - Create:
                    sudo touch /etc/modprobe.d/blacklist-nouveau.conf
                    v /etc/modprobe.d/blacklist-nouveau.conf
                - Add following lines
                    blacklist nouveau
                    options nouveau modeset=0
            - Regenerate kernel:
                    sudo update-initramfs -u
                    sudo reboot

    - Required (paths):
        - add to ~/.bashrc.local
            export PATH="/usr/local/cuda-11.x/bin:$PATH"
            export LD_LIBRARY_PATH="$LD_LIBRARY_PATH:/usr/local/cuda-11.x/lib64"
        - OR ADD
            - /usr/local/cuda-11.1/lib64 to `/etc/ld.so.conf`
            - run `ldconfig` as root
