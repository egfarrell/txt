- disassemble a file: `objdump -d myprog > myprog.d`
- movq - quad word - 64 bits
- MEMORY ADDRESSING modes:
    - `(%rdi)`    get ADDRESS of `%rdi` register
      - (register in brackets is like a pointer)
    - `10(%rdi)`  constant DISPLACEMENT offset of `%rdi` address
    - `D(Rb, Ri, S)` Most general form!
        - D:  Constant displacement
        - Rb: Base register
        - Ri: Index register
        - S:  Scale (1, 2 or 4 byes)

### `leaq` or `leal` - Load Effective Address
    - leaq Src, Dest
    - used to mimic: p = &x[i];
    - ie puts the ADDRESS of the `Src` in the `Dest`
    - Also used for arithmetic addition!!!
    - computes arithmetic expressions of form `b + s*i (+ d)`
      where s = 1,2,4 or 8
    - this doesnt set certain 'flags' cos technically its not an
      arithmetic instruction
    - (looks like youre manipulating addresses but actually
      clever way of addition)

### basic approach
    - 1. _load_: (values from memory into registers)
    - 2. _process_: (do something with the registers)
    - 3. _store_: (put values back into memory)
    - note: registers much quicker than memory (even cache)
    - note: can't operate on two things in MEMORY at the same
      time. ie both operands can't be memory (one must be
      register etc)

### program counter
    - processor register holding memory address of next
      instruction to be executed
    - PC: Program Counter
    - IP: Instruction Pointer (called IP on Intel)
    - IAR: Instruction Address Register
    - RIP: instruction pointer for x86-64 (or is it "Return
      Instruction Pointer"???)

### x86 assembly language
    - https://en.wikipedia.org/wiki/X86_assembly_language#Syntax
    - TWO syntax branches:

    - INTEL:
        - move {destination}, {source}
        - `mov eax, 5`
        - originally used for x86 documentation
        - dominant in MS-DOS and Windows
        - used by: NASM, FASM, MASM, TASM, and YASM

    - AT&T:
        - move {source}, {destination}
        - `mov $5, %eax`
        - dominant in Unix world
        - (cos Unix created at AT&T Bell Labs)
        - Used by: GAS
        - but GAS has `.intel_syntax` directive too

### Registers
    - Because theres so few of them, their address is only
      a small amount of bits (dont need a bit long address like
      somewhere in RAM)

    - 'LiveOverflow' tip: registers are like 'global variables'

    - data registers

    - address registers

    - addressing modes:
        - Register:   `Add R1, R2      // R2       <- R2 + R1`
        - Direct:     `Add R1, M[200]  // Mem[200] <- Mem[200] + R1`
        - Indirect:   `Add R1, @A      // Mem[A]   <- Mem[A] + R1`
        - Immediate:  `Add 73, R1      // R1       <- R1 + 73`

### Assembly Primer for Hackers (great stuff)

    - method 1: display stack/heap contents:
        1. Get process id: `ps -aux | grep SimpleDemo`
        2. Assume the pid is '1234'
        2. look at memory map: `cat /proc/1234/maps`

    - method 2: display stack/heap contents:
        - `pmap  $(pgrep simpledemo)`

    - linux virtual memory randomisation
        - look at it:  `cat /proc/sys/kernel/randomize_va_space`
        - turn off by: `echo 0 > /proc/sys/kernel/randomize_va_space`
