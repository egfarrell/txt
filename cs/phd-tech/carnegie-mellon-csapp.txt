### instructor comment
    - assembly code - text 'form'
    - object code   - binary 'form'
    - one-to-one mapping between them

### History 'x86'
    - first one '8086', then '8286' etc
    - is that the same as '286', '386', '486' etc?
    - x86 is a bit like English - quirky and idiosyncratic
    - x86 is 'CISC'
        - Complex Instruction Set Computer (versus RISC)
        - has 500 instructions, two big manuals

### ARM (Advanced RISC Machine)
      - Originally Acorn RISC Machine (Cambridge)
      - Lower power requirements than x86 (cos instruction set is
        simpler) and can be customised.

### ISA - [I]nstruction [S]et [A]rchitecture
    - higher level abstraction
    - part of processor design you need to understand to write
      assembly code. e.g. registers
    - Microarchitecture: 
        - actual low-level implementation of the architecture. 
        - e.g. cache sizes, core frequency
