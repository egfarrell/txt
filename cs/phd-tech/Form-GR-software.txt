### Build FORM
    - I used prefix: /work/efarrell/local
    - install LZIP (to inflate GMP tar):                       https://www.nongnu.org/lzip/
    - install GMP (GNU Multiple Precision Arithmetic Library): https://gmplib.org/
    - install ZLIB:                                            https://zlib.net/
    ```
    ./configure --prefix="/work/efarrell/local" --with-gmp=/work/efarrell/local --with-zlib=/work/efarrell/local
    ```
