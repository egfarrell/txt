# Foundations of RL

- Homepage https://classroom.udacity.com/nanodegrees/nd893/parts/8f607726-757e-4ef5-8b64-f2368755b89a

### 01: Introduction to RL
    - A friendly introduction to reinforcement learning.

### 02: RL: The Problem
    - Learn how to define Markov Decision Processes to solve
      real-world problems.

### 03: RL: The Solution
    - Learn about policies and value functions.
    - Derive the Bellman equations.

### 04: Dynamic Programming
    - Write your own implementations of iterative policy
      evaluation, policy improvement, policy iteration, and value
      iteration.

### 05: Monte Carlo methods.
    - Implement classic Monte Carlo prediction and control
      Methods
    - Learn about greedy and epsilon-greedy policies.
    - Explore solutions to the Exploration-Exploitation Dilemma.

### 06: Temporal-Difference Methods
    - Learn the difference between the Sarsa, Q-Learning, and
      Expected Sarsa algorithms.

### 07: Solve Openai Gyms Taxi
    - V2 Task
    - Design your own algorithm to solve a classical problem from
      the research community.

### 08: RL In Continuous Spaces
    - Learn how to adapt traditional algorithms to work with
      continuous spaces.
