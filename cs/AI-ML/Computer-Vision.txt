### Alternatives to DL
 
    1. Template Matching: 
        - a smaller image or template is slid over a larger image
          to find areas that match the template. It's useful for
          _simple_ pattern recognition tasks.

    2. Feature Detection and Matching: 
        - Detect and describe local features in images: 
            - SIFT: Scale-Invariant Feature Transform, 
            - SURF: Speeded Up Robust Features, 
            - ORB: Oriented FAST and Rotated BRIEF
            - These features can be used for tasks like object
              recognition, image stitching, and tracking.
        - SIFT 
            - created in 2004 by D. Lowe at the University of
              British Columbia to solve the problem of scale
              variance for feature extraction. SIFT can be broken
              down into two parts: key-point detection and
              key-point descriptor extraction.
        - SURF 
            - created as an improvement on SIFT in 2006, aimed at
              increasing the algorithm speed.
        - ORB 
            - a combination of FAST and BRIEF Algorithms and
              created in 2011 as an alternative to SIFT and SURF.
        - ORB performed best on a little test I read about
            - https://mikhail-kennerley.medium.com/a-comparison-of-sift-surf-and-orb-on-opencv-59119b9ec3d0

    3. Edge Detection: 
        - Canny, Sobel, and Prewitt operators detect edges in
          images, which is a fundamental step in many vision
          tasks, including object detection and image
          segmentation.

    4. Histogram of Oriented Gradients (HOG): 
        - A feature descriptor for object detection tasks,
          notably in pedestrian detection. Counts occurrences of
          _gradient orientation_ in localized portions of an
          image.

    5. Optical Flow: 
        - Algorithms estimating the _motion_ of objects between
          two frames of a video sequence based on apparent motion
          of patterns in the image. It's used in tracking and
          motion analysis.

    6. (SfM) Stereo Vision and Structure from Motion : 
        - Techniques to estimate the 3D structure of a scene from
          a set of 2D images. 
        - Stereo vision uses images from two cameras, while SfM
          reconstructs 3D structure from images taken at
          different viewpoints.

    7. Color Space Analysis: 
        - Using color models (eg RGB, HSV, Lab) for tasks like
          skin detection, object tracking, and scene
          understanding. Color-based segmentation and filtering
          are common applications.

    8. Morphological Operations: 
        - Non-linear operations related to the shape or
          morphology of features in an image, including dilation,
          erosion, opening, and closing. 
        - Useful in pre-processing for removing noise or for
          post-processing of binary images.

    9. Classical Machine Learning: 
        - Before DL, machine learning techniques such as Support
          Vector Machines (SVM), Random Forests, and AdaBoost
          were used with handcrafted features extracted from
          images for classification and regression tasks.

    10. Graphical Models: 
        - Including Markov Random Fields (MRFs) and Conditional
          Random Fields (CRFs) for image segmentation and
          labeling tasks, where the spatial relationships and
          context within images are modeled explicitly.

    - While deep learning has become the dominant approach due to
      its ability to learn complex patterns and perform
      end-to-end learning from raw data, traditional methods are
      still relevant. 
        - They can be more interpretable, require less data, and
          sometimes computationally less intensive. 
        - They are also used in conjunction with DL methods to
          solve specific problems more efficiently.

### Good computer vision libraries

    1. _Convolutional Neural Networks (CNNs)_: Basic but
       powerful. Used as a base for many other architectures.
       Example: LeNet-5 for handwritten digit recognition.

    2. _VGGNet_: Introduced the use of small, 3x3 convolutions.
       Stacks many such layers. High resource requirements but
       still effective.

    3. _ResNet (Residual Networks)_: Utilizes "skip
       connections" or "shortcuts" to make training deep networks
       easier. Imagine you’re in a maze; shortcuts help you get
       to the destination without going through all possible
       paths.

    4. _Inception Networks (GoogLeNet)_: Uses "inception
       modules" that have multiple filter sizes in parallel. Like
       having various sizes of nets to catch different fish in
       the same sea.

    5. _DenseNet_: Connects each layer’s output to every other
       layer’s input in a feed-forward manner. Imagine
       a community where everyone talks to everyone, sharing
       information efficiently.

    6. _EfficientNet_: Scales the architecture's depth, width,
       and resolution based on a compound coefficient. Like
       fine-tuning the knobs on an amplifier for best sound
       quality.

    7. _MobileNet_: Optimized for mobile and embedded devices.
       Think of it as a lightweight suitcase with only essential
       items but still functional for a trip.

    8. _NASNet (Neural Architecture Search)_: Uses machine
       learning to find the best architecture. It's as if a robot
       were to design the most efficient car by testing multiple
       designs.

    9. _Vision Transformer (ViT)_: Adapts Transformer models
       from NLP to image classification. Think of each image as
       a sentence, where each pixel or patch is a word. The model
       tries to understand the entire context.

    10. _Swin Transformer_: Builds upon Vision Transformer but
        adds "sliding window" attention. This is like scanning
        a book page with a moving magnifier to understand the
        text better.

    11. _MLP-Mixer_: Relies on multi-layer perceptrons and
        avoids convolutions. Simple but surprisingly effective.

    - Different architectures excel in different use-cases. E.g.,
        - constrained resources: MobileNets 
        - accuracy: EfficientNet and Vision Transformers 

### Alternatives to CNNs and ViTs

    1. Region-based Convolutional Neural Networks (R-CNN):
        - This family of methods includes R-CNN, Fast R-CNN, and
          Faster R-CNN. They involve generating region proposals
          and then classifying and refining these proposals using
          CNNs.

    2. Single Shot Detectors (SSDs):
        - SSDs are designed to perform object detection in
          a single forward pass of the network. They achieve this
          by predicting the class and location of objects at
          multiple scales within the same network.

    3. You Only Look Once (YOLO):
        - Another single-pass object detection algorithm that
          divides the input image into a grid and predicts
          bounding boxes and class probabilities directly from
          the grid cells.

    4. EfficientDet:
        - EfficientDet is a recent advancement in object
          detection that uses efficient model architectures
          (e.g., EfficientNet) and combines them with the focal
          loss and the bi-directional feature pyramid network
          (BiFPN) for improved efficiency and accuracy.

    5. CenterNet:
        - CenterNet is a simple and efficient approach that
          directly predicts object centers and their bounding
          boxes, along with other attributes like object size or
          orientation.

    6. Spatial Transformer Networks (STNs):
        - STNs are a different paradigm that focuses on learning
          spatial transformations to improve the spatial
          invariance of the model.

    7. Graph Neural Networks (GNNs):
        - GNNs can be used for object detection by treating
          objects and their relationships as nodes and edges in
          a graph, enabling the model to reason about object
          interactions.
