### Kernel Size
    - 2012: Alexnet 11x11 kernel, then 5x5, then 3x3
    - 2014: `3x3` is king!
        - VGG: Visual Geometry Group (Ofxord) 
        - Why? 
        - A chain of two `3x3` kernels , the second layer has
          a receptive field of `5x5`
        - So two 3x3's is the same as one 5x5
            - but two 3x3's is computationally more efficient. 
            - Smaller kernles mean fewer weights and fewer
              computations.
            - A chain of three 3x3's uses 50% ofthe resources of
              a single 7x7
                - $MY_IMAGES/cs/AI-ML/CNN-chain-kernels-efficiently.jpg
        - EXCEPTION: 
            - the 1st layer is often 5x5 or 7x7: because the
              input normally has only 3 channels
    - But: `1x1` also popular. 
        - Least expensive way to change the number of features in
          your feature map

### CNN: variable input sizes
    - aka: the pixel resolution of training images

    - When you train a CNN for image classification, you
      typically use a fixed input size because the fully
      connected layers (often come after the convolutional and
      pooling layers) expect a _fixed-size input_. 
        - Therefore, the resolution of the input directly affects
          the number of neurons and weights in these layers.

    - Given this architecture constraint, when you classify
      a new, unknown image using a trained CNN:

    1. _You must resize the test image to the same resolution the
       model expects._ If your CNN was trained with 300x300 pixel
       images, you would typically resize your test image to
       300x300 pixels before feeding it into the model.

    2. The reason for resizing is two-fold:

        a. _Architectural Constraint:_ As mentioned, fully
        connected layers expect a fixed size input. If you don't
        resize the test image to match the input size the network
        was trained on, you'll encounter dimensionality errors.

        b. _Feature Consistency:_ During training, the CNN learns
        features at various scales based on the given input size.
        If you input an image of a different resolution during
        inference, the scale of the features might differ from
        what the network expects, leading to inaccurate
        predictions.

    3. _However, important note:_ Directly resizing images can
       introduce distortions if the `aspect ratio` of the
       original image is not the same as the target resolution.
        - If the original image is not square (in the case of
          a 300x300 target size), consider the following steps:

            a. _Resize the image:_ Resize the longer dimension of
            the image to 300 pixels while keeping the aspect
            ratio the same.

            b. _Pad the image:_ Pad the shorter side with a constant
            value (often zero) or by mirroring the image edges until
            it becomes 300 pixels. This way, you prevent any
            unnatural distortions.

    - Also: some advanced models or techniques might use
      `adaptive pooling` or `global average pooling layers` which
      can handle variable input sizes. 
        - However, for traditional CNNs with fully connected
          layers at the end, the input size must be consistent
          with the trained resolution.
