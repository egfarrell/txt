### 03-Loss-Functions-and-Optimization
    - You have `x`s and `y`s
        - `x` = input image pixels
        - `y` = "label" or "target"
    - Loss
        - $MY_IMAGES/cs/AI-ML/computer-vision/loss-functino.jpg
    - multiclass SVM loss:
        - sum the scores for all the incorrect categories
        - is the `∑ incorrect` < score correct category?
        - often called 'hinge loss' too
            - $MY_IMAGES/cs/AI-ML/computer-vision/hinge-loss.jpg
        - loss for 'cat'
            - $MY_IMAGES/cs/AI-ML/computer-vision/hinge-loss-svm-example.jpg
        - loss for 'car' (no loss!)
            - $MY_IMAGES/cs/AI-ML/computer-vision/hinge-loss-svm-example-2.jpg
        - loss for 'frog' (model is bad here)
            - $MY_IMAGES/cs/AI-ML/computer-vision/hinge-loss-svm-example-3.jpg
    - Lecturer questions
        - the weights are initialised to small random values, so
          after the first pass, what should the loss be: `C - 1`
          where `C` is the number of target classes
        - He said this is useful for debugging...
            - $MY_IMAGES/cs/AI-ML/computer-vision/hinge-loss-first-pass.jpg
    - Sometimes you can have a '`squared`' hinge loss function
        - ie a non-linear loss function. The loss function is
          a way of telling the algorithm what errors you care
          about.
    - Note: the final correct weights `w` aren't unique!
        - You could double the weights `2w` the loss function
          would still be zero.
        - This raises an interesting point. So far, we've only
          focussed our loss function on the training data only.
        - But in reality, we want to classify unknown test data.
        - So we should introduce "REGULARISATION"
        - ie we introduce a regularisation "penalty term" to the
          loss function (separate from the data loss term) which
          encourages the model to pick 'simpler' `w`s
            - ie we force the model to be simpler so it will do
              better on unseen test data
            - note: regularisation depends on a hyper-parameter
              `λ` that has to be tuned
            - $MY_IMAGES/cs/AI-ML/computer-vision/svm-regularisation.jpg
    - types of regularisation:
        - $MY_IMAGES/cs/AI-ML/computer-vision/types-of-regularisation.jpg


### 02-Image-Classification
    - LINEAR classifiers (TEMPLATE matching)
        - The bias term is DATA INDEPENDENT.
            - We can use it to boost certain classes.

        - Weights: 3 decision classes so the weights "matrix" has
          dimension 3 rows...
            - $MY_IMAGES/cs/AI-ML/computer-vision/basic-setup-linear-classification.jpg

        - You can unravel the trained weights to see what it
          regards as a 'template' for each class
            - $MY_IMAGES/cs/AI-ML/computer-vision/linear-classifier-visualise-weights.jpg
            - But disadvantage for linear classifiers:
                - it only has ONE template for each class (target
                  category)
            - It's trying to average out ALL the differences for
              a single class (e.g. a phone) and just use that one
              template for all pictures of a phone

        - Another way of interpreting a LINEAR classifier
            - An image is high-dimensional data , and the
              classifier is trying to draw linear decision
              BOUNDARIES
