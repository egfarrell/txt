### Install (Ubuntu 18.04)
    - https://docs.docker.com/engine/install/ubuntu/
    # How to install Docker on Ubuntu 18.04

    # Step 1: Cleanup + prerequisites
        
        sudo apt-get remove docker docker-engine docker.io containerd runc
        sudo apt-get update
        sudo apt-get install apt-transport-https ca-certificates curl gnupg-agent software-properties-common

    # add docker GPG key
        curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -

    # The key should be: 9DC8 5822 9FC7 DD38 854A E2D8 8D81 803C 0EBF CD88
        sudo apt-key fingerprint 0EBFCD88

    # Add repo
        sudo add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"

    # Now Install docker
        sudo apt-get update
        sudo apt-get install docker-ce docker-ce-cli containerd.io
        
    # Test Docker to see if it works...
        sudo docker run hello-world

### "Dockerfile"
    - A `Dockerfile` is a text-based script of instructions used
      to create a container image
    - Might have a final line to auto-execute a script on
      startup. eg:
        - `CMD ["/bin/bash", "/codeexecution/entrypoint.sh"]`


### Dont require "sudo" for docker
    - first:
        sudo groupadd docker

    - Add the connected user "${USER}" to the docker group.
    - Change the user name to match your preferred user:
        sudo gpasswd -a ${USER} docker

    - Restart Docker daemon:
        sudo service docker restart
        - If on Ubuntu 14.04-15.10 use "docker.io" instead:
            sudo service docker.io restart
