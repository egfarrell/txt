### Remove Ugly fonts in Poke 3
    - These instructions gave me access to Android settings but
      didn't really fix the ugly fonts problem:
        - Step 1: Enable developer mode
            - not accessisble thru standard Onyx interface
            - Install Dev Tools (Android Developer)
            - Goto Settings -> About Tablet ->
                    - click on Build number 7 times
        - Step 2:
        - Start all apps on "Android Settings" mode
            - Change developer options using this app:
            - https://play.google.com/store/apps/details?id=com.singlebyte.devshortcut


    - Another way: Change app "Bleach" settings
        - (BUT THIS MAKES ALL WHITE TXT DISAPPAEAR IN TERMUX)
        - Long Press app -> Optimize -> Bleach ->
            - Add strokes to text = 0
            - Background Color = 255
