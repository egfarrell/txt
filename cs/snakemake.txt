
### Random Thoughts
    - Snakemake is much more focused on `naming files` in a way
      that you can figure out what input data and _parameters_ were
      used to produce them, making it easier to compare results
      from variations on the main analysis. 

    - Versioning: The way a workflow like Snakemake can help here
      is by letting the filenames pretty much describe how each
      particular output was created, meaning data outputs can act
      as immutable in a sense.
        - What I mean is that rather than create a _new version_
          of a file, if you run the same analysis with different
          sets of parameters, it should generate a new file with
          a different name rather than a new version of the old
          one. This also helps comparing differences between
          output from different parameters etc.
