### Import Styles from another Document
    - In the document you have created your styles and headings,
      go to the 'Design' tab and click the downward arrow on the
      style sets. Then choose 'Save as a New Style Set'. A popup
      window will open to save the style set as a Word Template
      (*.dotx). Type in a name for the template style set and
      save it.
    - In the new document where you want to use these styles, go
      again to the 'Design' tab and click the downward arrow on
      the styles sets. Then choose your saved template style set
      under 'Custom'. The style set will apply to your headings
      (if included in the template) and you can choose those
      styles for any paragraph.

### Make Word 2016 FAST
    - Note: `winword /a`  (no addons, very quick)
    - Aim: change file type association for Word.
        - open cmd window as ADMINISTRATOR
        - type "ftype"
            - Should see:
                `Word.Document.12="C:\Program Files (x86)\Microsoft Office\Root\Office16\WINWORD.EXE" /n "%1" /o "%u"`
        - Now over-ride ftype definition to use `/a`
        - Paste the following into cmd:
            ftype Word.Document.12="C:\Program Files (x86)\Microsoft Office\Root\Office16\WINWORD.EXE" /a "%1" /o "%u"
            ftype Word.Document.8="C:\Program Files (x86)\Microsoft Office\Root\Office16\WINWORD.EXE" /a "%1" /o "%u"

    - Old Method: Create a Batch file:
            @echo off
            start "" "C:\Program Files (x86)\Microsoft Office\root\Office16\WINWORD.EXE" /a %1
            REM  "C:\Program Files (x86)\Microsoft Office\root\Office16\WINWORD.EXE" /a %1
