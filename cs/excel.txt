### handy
    =VLOOKUP(A1, Table1[JR Reference], 1, FALSE) <--- EXACT match
    =VLOOKUP(A1, D1:2234343, 1, FALSE)           <--- EXACT match
    =VLOOKUP(A1, Table1[JR Reference], 1, TRUE)  <--- EXACT match


    - Note: VLOOKUP must have the target data we want to retrieve
      to the _RIGHT_ of our lookup match values

    - handle "#N/A" error
        =IFERROR(VLOOKUP(A2, TREVOR_QUERY!$A$1:$L$9562, 1, FALSE), "No")

    - Return "Yes" or "No"
        =IF(ISNA(VLOOKUP(A2,$D$2:$D$185,1,FALSE)), "No", "Yes")

    - Ctrl + shift + +         : Insert row/column

### freeze multiple rows/columns
    - Select the cell immediately _BELOW_ and to the _RIGHT_ of
      the rows and columns that you want to freeze. 
    - View -> Freeze Panes -> Freeze Panes

### copy print settings to many sheets
    - hold CTRL and click on each sheet tab
    - then click on "Page Setup"
    - any changes in "Page Setup" will apply to all sheets

### my macro:
    - in DCG press ctrl+shift+n to do basic formatting on a new
      sheet
    - macro was recorded under the "View" -> "Macros" -> "Record Macro..."
    - its stored in "personal.xlsb" in folder:
        - C:\Users\<username>\AppData\Roaming\Microsoft\Excel\XLSTART


        ```
        Sub Basic_Formatting()
        '
        ' Basic_Formatting Macro
        ' Get basic spreadsheet setup
        '

        '
            With Selection
                .HorizontalAlignment = xlLeft
                .VerticalAlignment = xlBottom
                .WrapText = False
                .Orientation = 0
                .AddIndent = False
                .IndentLevel = 0
                .ShrinkToFit = False
                .ReadingOrder = xlContext
                .MergeCells = False
            End With
            Columns("E:E").EntireColumn.AutoFit
            Range("A1").Select
            Range(Selection, Selection.End(xlToRight)).Select
            Selection.Style = "Note"
            Selection.Font.Bold = True
            Selection.AutoFilter
            Cells.Select
            Cells.EntireColumn.AutoFit
            
            With ActiveWindow
                If .FreezePanes Then .FreezePanes = False
                .SplitColumn = 0
                .SplitRow = 1
                .FreezePanes = True
            End With
            Range("A4").Select
            
        End Sub
        ```

### unpivot data using "PowerQuery"
    - convert range of data into a table (if not already a table)
    - goto _Data_ tab
    - click _From Table/Range_ (in "Get and Transform Data" section)
    - A Power Query window opens:
        - highlight the columns you want to unpivot
        - goto _Transform_ tab
        - click _Unpivot Columns_
    - Finally click "Close and Load" to bring transformed
      database back to a new worksheet

### misc
    - "mapfill" feature

    - forecast sheet: show trend lines

    - 3D referencing: reference other sheets

    - any kind of summarising stuff: use PIVOT TABLES!

    - what-if-analysis: "goal seek"

    - cell colour standards: there's a standard colour to let
      people know the contents of this cell are calculated.
      (orange)


    tables: if you've a problem adding new row to a range then use TABLES!
    tables: turn on "total row"
    tables: make sure to name your tables
    tables: will auto-name columns eg `[@salary]`

    dont use VLOOKUP: use INDEX and MATCH!
        - vlookup is not self-documenting and is slow
        - `MATCH(location, tax_juristiction)`
        - `INDEX(tax_rates, match(location, tax_juristiction))`

    Name Manager (formula tab):
        - name individual cells: eg tax-rate. Write variable name where it gives row/col reference (self-documenting spreadsheet)
        - name entire columns:   eg salary column.

    format painter
    filter by colour
    "name a range" e.g. paid_range
    F4: make range absolute
    missing vlookup entries:
        =IFERROR(VLOOKUP(D12, paid_range, 1, false), "NOT PAID")
        =ISNA(VLOOKUP(D12, paid_range, 1, false))
