Fixtures
    When testing, the "fixtures" are inputs 
    to a function or data file to be processed.

Interface:
    softwares "contract" with the outside world

Implementation:
    nuts and bolts of how it does it

For testing, depend on INTERFACE not on implementation.
    This means we can replace functions we are 
    not currently testing with simplified versions.

StringIO
    is a Python function that simulates reading and writing to a disk
    file. ".getvalue" is a method supplied by StringIO which checks what
    was written.

Some test output is stored in SET objects, 
so SORT the set before checking test results.

Discussion about float-point numbers.
    Read "What every computer scientist should know about floating point numbers"

Absolute Error = |val-approx|
Relative Error = |val-approx|/ val

Relative error is more useful.

Never use == or != with floating point numbers.
    Its ok to trust >, >= though.
    Instead use nose.assert_almost_equals which uses a tolerance.

Setup function
