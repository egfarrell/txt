### copy to android clipboard
    - note:  must use github version of termux
    1. from firefox: install `termux API app` from github (not Fdroid) v0.50.1
    2. from termux terminal: pkg install `termux-api`
    3. pkg uninstall xclip

    set specific permissions:
        cd $PREFIX/libexec
        cd termux-am/
        chmod 400 am.apk

    test:
        termux-clipboard-set "text"

### How I installed exuberant ctags
    - solution 2024, lenovo m10
        - install universal ctags, activate vim plugin 'tagbar-universal' from my $HOME/.vim

        - solution: build ON DEVICE
        - doesn't work on Android 13, although it does on android 9,10,11
            - Step 1: 
                > setup termux build
                    g clone --depth 1 https://github.com/termux/termux-packages
                    c termux-packages/
                    ./scripts/setup-termux.sh

            - Step 2: 
                > compile source
                    cp ~/dotfiles/ini/termux/ctags-5.8.tar.gz  ~/repos
                        - old way:
                        wget http://prdownloads.sourceforge.net/ctags/ctags-5.8.tar.gz
                    c ~/repos
                    utar ctags-5.8.tar.gz
                    c ctags-5.8
                    ./configure --prefix=$PREFIX
                    make
                    make install

    - ### Other build info
       - Build package             https://wiki.termux.com/wiki/Building_packages
       - Create new package        https://github.com/termux/termux-packages/wiki/Creating-new-package
       - Example: (building ctags) $HOME/dotfiles/ini/termux/old/ctags_build.sh




### View Termux $HOME folder
    - The file manager needs to support SAF (Storage Access Framework) to view Termux $HOME/folder
    - Use: FX File Explorer (NextApp Inc.) from Google Play Store
        - click on the '3 dots' in top right-hand corner
        - click "Connect to Storage"
        - on the lhs menu, choose "Termux"
        - click "use this folder"
