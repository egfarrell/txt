Video 2 was all about: functional programming, mutable state,
pure and impure functions. Great stuff.

- Every Clojure datatype is defined in terms of Java classes.
- Code in either language can invoke code in the other.
- Invoking Java code from Clojure is convenient because Clojure
  has special syntax for doing so.
- Actually Clojure defers directly to the traditional Java
  classes for File IO.
- Clojure DOES NOT HAVE inheritance or encapsulation, but has
  Polymorphism

- A MACRO is a special function invoked at compile time, not at
  execution time
    - note: a macro could return another macro, which must be
      resolved in turn

### special forms
    - if the first element in a list doesn't resolve to
      a function or a macro, then before throwing an error, the
      compiler will check if it matches one of the "16 special
      forms".

### subtle point: "monkey patching"
    - functions can change after definition, because the function
      body may reference a _symbol_ 'foo' but the _var_ sitting
      behind this symbol may change later
    - arguably this affects 'functional purity'
    - the reason Clojure does this, and the reason namespaces map
      symbols to vars, instead of mapping symbols directly to
      other values, is so your code can be updated at RUNTIME.
    - This capacity for "monkey patching" is handy for debugging
      and for live-patching running systems.
        - full explanation:
        - "When symbols in the function body are resolved to the
          current namespace, you should think of them as
          resolving to the vars themselves, instead of to the
          VALUES of those vars."
        - "When the vars change their value, the values used in
          the function change too"

### namespaces
    - when clojure runtime starts, current namespace is `user`
      which contains all of `clojure.core`
    - create a namespace: (in-ns 'foo)
        - the `foo` namespace will be completely blank, without
          clojure.core
    - 4 types of namespace mappings
        - symbol-to-var (interned)
        - symbol-to-var (referred)
        - symbol-to-class
        - symbol-to-namespace

    - symbol-to-var (interned)
        - this is just the normal `def`, `defn` etc
    - symbol-to-var (referred)
        - $MY_IMAGES/cs/clojure/refer-mappings.jpg
        - $MY_IMAGES/cs/clojure/refer-mappings-name-collisions.jpg
    - symbol-to-class
        - create map to java class using import macro
        - $MY_IMAGES/cs/clojure/mappings-to-java-classes-import.jpg
    - symbol-to-namespace
        - use alias to refer to another namespace
        - $MY_IMAGES/cs/clojure/mappings-to-namespaces-alias.jpg

### Sets
    - all elements unique
    - sets are like maps, but all keys are their own values (ie
      maps have key/value pairs, but sets just have keys)
    - clojure has 2 types of sets:

        -  `hash-set`
            - (no sense of order)

        -  `sorted-set`
            - ("tree set", keep elements in sorted order)
            - sorting is done by the compare function so all
              elements must be numbers
            - can use a different compare function if you want:
            - (def s (sorted-set `>` 7 2 -5 9))

    - $MY_IMAGES/cs/clojure/sets-examples.jpg
    - must use `disj` (disjoint) to remove elements in a set (not
      `dissoc`)

### Collections
    - collection objects are actually functions!

        - this returns "5", the value at idx 1
    - invoke map as a function
        - ({:x 9, :y 4} :y)
