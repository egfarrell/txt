### toltec: Package manager ("opkg")
    - https://toltec-dev.org/#install-toltec
    - Warning: Toltec only supports OS builds between 2.6.1.71
      and 2.15.1.1189. 
    - You will soft-brick your device if you install on an
      unsupported version. 
    - See https://remarkable.guide/tech/recovery.html for
      recovery info if you have done this. 

    opkg update
    opkg upgrade
    opkg list
    opkg list | grep -i build
    opkg install <package>
    opkg remove <package>
    opkg info <package>
    examples:
        opkg info yaft

    - to manage 'toltec' installation
        toltecctl help
        toltecctl reenable
        toltecctl generate-opkg-conf
        toltecctl uninstall
        toltecctl switch-branch my_test_branch

    /home/root/.bashrc
        - must include this line in the path
        PATH="/opt/bin:/opt/sbin:/home/root/.local/bin:$PATH"

### Compile exuberant ctags on tablet
    - COPY SOURCE CODE TO TABLET:
        scp ~/dotfiles/ini/termux/ctags-5.8.tar.gz remark:~/repos/
    - SSH TO TABLE. THEN:
        utar ctags-5.8.tar.gz
        cd ctags-5.8
        ./configure --prefix=/home/root/.local
        make
        cp ctags ~/.local/bin/


### 'Oxide' launcher
    - REMOVE security pin
        xdg-settings set pin ''
    - installation
        - opkg install oxide
        - for 'oxide' launcher gestures
        - enable swipes
            - (by swiping down from the top)
        - then when swipes are ENABLED,
            - swipe up from the bottom to return to lanucher screen

### Use KOReader as your
    first disable Oxide
        systemctl disable --now tarnish
    (or disable xochitl)
        systemctl disable --now xochitl
    then enable koreader
        systemctl --now enable koreader
