

### Binary Image ('mask')
    - A binary image is an image where each pixel can have only
      one of two possible values, typically represented as black
      and white, or 0 and 1. It's a simple form of image
      representation used for tasks like object segmentation,
      where pixels are either considered part of an object (1) or
      not (0).

### 8-bit v 'float' images
    - 8-bit and floating-point (0.0 to 1.0) representations in
      RGB images have their own advantages and disadvantages:

    ### Advantages of 8-bit (0 to 255) format:
    1. Compactness: 8-bit images use less memory and storage
       compared to floating-point images, which is advantageous
       when working with limited resources.
    2. Compatibility: Many image processing libraries and
       hardware devices are optimized for 8-bit images, making
       them a widely supported format.
    3. Easy Visualization: The 8-bit format maps directly to the
       0-255 range, making it easier to understand and visualize
       pixel values.

    ### Disadvantages of 8-bit format:
    1. Limited Precision: 8-bit images have limited precision,
       which can lead to loss of subtle details and color
       accuracy, especially in high-contrast or low-light
       situations.
    2. Clipping: Values outside the 0-255 range may be clipped,
       resulting in data loss.

    ### Advantages of floating-point (0.0 to 1.0) format:
    1. High Precision: Floating-point images offer higher
       precision, allowing for better representation of subtle
       color variations and details, especially in HDR (High
       Dynamic Range) imaging.
    2. No Clipping: Floating-point format can represent values
       outside the 0-1 range without clipping, which is useful in
       certain image processing tasks.
    3. Compatibility with Some Algorithms: Some image processing
       algorithms, like those used in deep learning, work better
       with floating-point input due to their flexibility.

    ### Disadvantages of floating-point format:
    1. Larger Storage: Floating-point images require more memory
       and storage compared to 8-bit images, which can be
       a limitation in resource-constrained environments.
    2. Compatibility Challenges: Not all image processing
       software and hardware may support floating-point images,
       leading to potential compatibility issues. In summary, the
       choice between 8-bit and floating-point RGB formats
       depends on your specific use case. If memory and
       compatibility are critical, 8-bit is a good choice.
       However, if you need high precision and are willing to
       handle larger file sizes, floating-point format can be
       advantageous for preserving image quality and detail.



### PIL 
    - from PIL import Image 
    - # Greyscale image 
    - grey_image = Image.open('greyscale.jpg').convert('L')
    - Without `convert('L')` in PIL, the `grey_image` would still
      be loaded, but it would be in RGB format. 
    - However, all three color channels (R, G, and B) would have
      the same values, making it effectively a greyscale image,
      but with unnecessary color channels. It would be in RGB
      format, but visually indistinguishable from a true
      greyscale image.

### Pixels per cm
    - The `PixelX` column indicates how many centimeters are
      represented by the WIDTH of one pixel in the image 
        - (i.e. cm/pixel). 
    - The `PixelY` column indicates how many centimeters are
      represented by the HEIGHT of one pixel in the image.
    - If there was an ultrasound image of a breast and `PixelX`
      was `0.1`, (i.e. 0.1 cm/pixel) this means the width of 10
      pixels in the image equals 1 centimeter in real life.
    - Now, say a lump on the breast ultrasound image is 30 pixels
      wide in the image. Given our `PixelX` value of `0.1
      cm/pixel`, you'd determine that the lump is 3 centimeters
      wide in real life.
    - In this context, understanding pixel size in relation to
      real-world centimeters is crucial for medical
      professionals. 
        - They can estimate the size and extent of abnormalities
          seen in ultrasound images and make informed decisions
          based on these measurements.
