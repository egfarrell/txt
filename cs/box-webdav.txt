### Create Lubuntu manual mount 
    - File 1: /etc/fstab
        - make sure you have "noauto"!
        - can mess up if no network connection
        https://dav.box.com/dav /home/ef/Documents/box davfs user,rw,noauto 0 0
    - File 2: ~/.davfs2/secrets
        /home/ef/Documents/box ef.xxxxx@gmx.com <password>
    - Commands: 
        `mount ~/box`
        `umount ~/box`
        Or my aliases:
            - `mbox`
            - `ubox`
