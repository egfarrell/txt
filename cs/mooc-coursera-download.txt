### "CAUTH" trick
    - 1. USE COURSERA-DL FORK
        - Install this fork that uses the COURSERA V2 API
            - See:
              https://github.com/coursera-dl/coursera-dl/issues/834
                - Note 1:
                    - use Python 3.8, (not Python 3.9 because of
                      a weird error related to pip)
                conda create -n coursera python=3.8
                coa coursera
                pip3 uninstall coursera-dl
                cd ~/repos
                git clone https://github.com/raffaem/coursera-dl
                cd coursera-dl
                pip3 install .

    - 2. GET AUTH COOKIE
        - login to coursera.org
        - export 'cookies.txt' using firefox plugin
        - find CAUTH inside 'cookies.txt'
        - On bash command line:
            - `export CAUTH="...the long string from cookies.txt ..."`

    - 3. DOWNLOAD
        - (note: --list-courses won't work)
        coursera-dl -u "ef.tools@gmx.com" -p "Summertime1!" -ca $CAUTH  dsp1
        coursera-dl -u "ef.tools@gmx.com" -p "Summertime1!" -ca $CAUTH  single-variable-calculus
        coursera-dl -u "ef.tools@gmx.com" -p "Summertime1!" -c ./cookies.txt single-variable-calculus
