### HOW TO EMBED / INSERT

        - Local Gradio:
            - My gradio version, conda env 'rembg': : 3.44.4
            - My gradio version, conda env 'analiza2': 3.47.1
            - `src="https://gradio.s3-us-west-2.amazonaws.com/{GRADIO_VERSION}/gradio.js"`

            ```
                <script
                type="module"
                src="https://gradio.s3-us-west-2.amazonaws.com/3.47.1/gradio.js"
                ></script>

                <!--
                    Local gradio is serving from this port:
                        <gradio-app src="http://127.0.0.1:7860/"
                -->

                <!--
                    temporarily use a Hugging Face proxy link until Pierwsi
                    Apache server update (with reverse proxy)
                https://1c6f150f136a032b70.gradio.live
                http://138.68.110.214/gradio-app/
                -->

                <gradio-app src="https://1c6f150f136a032b70.gradio.live"
                eager="true"
                info="false"
                > </gradio-app>

            ```

            Embed hugging face

            ```
            <script
                type="module"
                src="https://gradio.s3-us-west-2.amazonaws.com/3.47.1/gradio.js"
            ></script>

            ```
