
### How do I create a custom plugin for image upload?

- Creating a custom WordPress plugin to allow external users to
  upload images from the frontend and then display those images
  on a page involves several steps. Here's a high-level overview
  of the process, along with some sample code snippets:

_Step 1: Set Up Your WordPress Plugin_

1. Create a new folder for your plugin in the `wp-content/plugins/` directory of your WordPress installation. Choose a unique name for your plugin, e.g., `custom-image-uploader`.

2. Inside your plugin folder, create a main PHP file for your plugin, e.g., `custom-image-uploader.php`. This file will serve as the entry point for your plugin.

3. Activate your plugin from the WordPress admin dashboard.

_Step 2: Create the Frontend Upload Form_

In your plugin's main PHP file (`custom-image-uploader.php`), you can create a shortcode that generates a form for users to upload images. Here's an example of how you can create a simple form:

```php
// Define a shortcode to display the upload form
function custom_image_upload_form() {
    ob_start(); // Start an output buffer

    // Display the HTML form
    ?>
    <form id="custom-image-upload-form" action="" method="post" enctype="multipart/form-data">
        <input type="file" name="custom_image" id="custom_image">
        <input type="submit" name="submit" value="Upload Image">
    </form>
    <?php

    // Get the buffered content and return it
    return ob_get_clean();
}
add_shortcode('custom_image_upload', 'custom_image_upload_form');
```

_Step 3: Handle Image Upload_

Now, you need to handle the image upload when the form is submitted. Add the following code to your plugin file to process the image upload:

```php
function handle_image_upload() {
    if (isset($_POST['submit'])) {
        $uploaded_image = $_FILES['custom_image'];

        if ($uploaded_image['error'] == 0) {
            $upload_dir = wp_upload_dir();
            $image_name = sanitize_file_name($uploaded_image['name']);
            $image_path = $upload_dir['path'] . '/' . $image_name;

            if (move_uploaded_file($uploaded_image['tmp_name'], $image_path)) {
                // Image uploaded successfully
                // You can save the image details in the database if needed

                // Display the uploaded image on the page
                echo '<img src="' . $upload_dir['url'] . '/' . $image_name . '" alt="Uploaded Image">';
            }
        }
    }
}
add_action('init', 'handle_image_upload');
```

_Step 4: Display the Upload Form on a Page_

Create a new page or edit an existing one in WordPress where you want to display the image upload form. Use the shortcode you defined earlier to display the form. For example, add `[custom_image_upload]` to your page content.

_Step 5: Style the Form_

You may want to style the form using CSS to make it visually appealing and user-friendly.

Remember to sanitize and validate user input and consider implementing additional security measures as needed to prevent unauthorized uploads and ensure the safety of your WordPress site.

With these steps and code snippets, you can create a custom WordPress plugin that allows external users to upload images from the frontend and displays those images on a page.



### How do I add css styling to this plugin.

- Certainly! To add CSS styling, you can ENQUEUE your stylesheet
  properly:

_Step 1: Create a CSS File_

First, create a CSS file (e.g., `custom-image-uploader.css`) and add your styles to it. Place this CSS file in your plugin folder.

For example, you might have styles like this:

```css
/* Add your custom CSS styles here */
#custom-image-upload-form {
    margin: 20px;
}

#custom_image {
    padding: 10px;
}

/* You can add more styles as needed */
```

_Step 2: Enqueue the CSS File_

In your plugin's main PHP file (`custom-image-uploader.php`), you'll need to enqueue your CSS file using WordPress's `wp_enqueue_style` function. You should do this by hooking into the `wp_enqueue_scripts` action, which ensures that your stylesheet is loaded on the frontend.

Here's an example of how to enqueue your CSS file:

```php
function enqueue_custom_styles() {
    // Get the URL of your plugin's folder
    $plugin_url = plugin_dir_url(__FILE__);

    // Enqueue your CSS file
    wp_enqueue_style('custom-image-uploader-css', $plugin_url . 'custom-image-uploader.css');
}
add_action('wp_enqueue_scripts', 'enqueue_custom_styles');
```

This code does the following:

- `plugin_dir_url(__FILE__)` gets the URL of your plugin's folder.
- `wp_enqueue_style` is used to enqueue your CSS file, and you give it a unique handle (`custom-image-uploader-css`) and specify the URL of your CSS file.

_Step 3: Apply the Styles to Your Plugin Elements_

Now that you've enqueued your CSS file, the styles you defined in `custom-image-uploader.css` will be applied to the elements on your plugin's frontend.

For example, the styles you defined for `#custom-image-upload-form` and `#custom_image` will affect the form and its elements.

Make sure your HTML elements in your plugin's shortcode (as shown in the previous answer) have the appropriate IDs or classes that match your CSS selectors for styling to take effect.

After completing these steps, your custom CSS styles should be applied to the frontend elements of your WordPress plugin, allowing you to customize the appearance of your image upload form and any other elements you want to style.


### How to run a Python script then?
To run a Python script to compress an image after it's uploaded using your custom WordPress plugin, you'll need to integrate Python into your WordPress environment. Here's a high-level overview of the steps involved and some sample code:

_Step 1: Create a Python Script for Image Compression_

- First, create a Python script that performs the image
  compression. You can use popular libraries like Pillow (PIL)
  for image manipulation. Here's a simple example using Pillow to
  compress an uploaded image:

```python
from PIL import Image

def compress_image(input_path, output_path, quality=85):
    try:
        image = Image.open(input_path)
        image.save(output_path, optimize=True, quality=quality)
        return True
    except Exception as e:
        print(f"Image compression failed: {str(e)}")
        return False

    # Example usage:
    # input_path = "path/to/uploaded/image.jpg"
    # output_path = "path/to/compressed/image.jpg"
    # compress_image(input_path, output_path)

```

This script takes an input image, compresses it with the specified quality, and saves the compressed image to the output path.

_Step 2: Execute the Python Script_

- After an image is uploaded via your WordPress plugin (as
  explained in a previous response), you can execute the Python
  script to compress the image. To do this, you'll need to call
  the Python script from your PHP code.

- You can use the `shell_exec` or `exec` function in PHP to run
  the Python script. Here's an example of how you might modify
  the code to execute the script after an image is uploaded:

```php
function handle_image_upload() {
    if (isset($_POST['submit'])) {
        $uploaded_image = $_FILES['custom_image'];

        if ($uploaded_image['error'] == 0) {
            $upload_dir = wp_upload_dir();
            $image_name = sanitize_file_name($uploaded_image['name']);
            $image_path = $upload_dir['path'] . '/' . $image_name;

            if (move_uploaded_file($uploaded_image['tmp_name'], $image_path)) {
                // Image uploaded successfully

                // Call the Python script to compress the image
                $python_script = 'path/to/compress_image.py';
                $input_path = escapeshellarg($image_path);
                $output_path = escapeshellarg($upload_dir['path'] . '/compressed/' . $image_name);
                $quality = 85;

                // Execute the Python script
                $command = "python $python_script $input_path $output_path $quality";
                shell_exec($command);

                // Display the compressed image on the page
                echo '<img src="' . $upload_dir['url'] . '/compressed/' . $image_name . '" alt="Uploaded and Compressed Image">';
            }
        }
    }
}
add_action('init', 'handle_image_upload');
```

- In this code, we've added the call to the Python script using
  `shell_exec`. Make sure to replace
  `'path/to/compress_image.py'` with the actual path to your
  Python script.

- Ensure that the Python environment on your web server is
  properly configured and that the required Python packages
  (e.g., Pillow) are installed.

- This code will upload an image, compress it using your Python
  script, and then display the compressed image on the page.
