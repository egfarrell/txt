### http redirect to HTTPS
    - cd /etc/apache2/sites-available
    - vim default-ssl.conf
    ```
    <VirtualHost *:80>
    ServerName $domain
    Redirect permanent / https://english-maths.club/
    </VirtualHost>
    ```
    - also: make sure port 80 is open:
    `ufw allow http`
