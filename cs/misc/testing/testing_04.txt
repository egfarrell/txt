Trade-offs in  Random Testing
	Advantages
		every fuzzer finds different bugs(!)
		less tester bias
		weaker hypothesis about where bugs are
		once testing automated, human cost is zero!
		often surprises testers and developers

	Disadvantages
		every fuzzer finds different bugs(!)
		input validity problem can be hard
		oracles hard to create
		no stopping criteria
		may find unimportant bugs
			i.e. if really weird rate input cases used
			then developers wont be interested in the bug
			e.g. variable name thats 800 characters long!
			solution: generate inputs that are more likely to be of interest
		may find same bug many times
			try to automatically reject repeat bugs
		hard to debug
			if test case very large and/or makes no sense
