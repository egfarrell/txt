### Python - Word Score Leaderboards
    - An environment in which you can develop Python code undisturbed for up to 2 hours.
    - Ideally you should use the latest stable Python version (3.4.x or later), but you can use version 2.7.x if you choose. Please include a comment to indicate the Python version you have used.
    - Ideally the challenge should be completed using only core language modules.
    - At the end of the time period, you will be expected to upload your completed code. Instructions will be provided when you begin the challenge.



### MySQL - GeekCoins analysis and reporting
    - Please ensure that you have 2 hours where you can work
      uninterrupted on the challenge.
    - You should have the ability to run MySQL server on your
      machine either with MySQL installed for your operating
      system (see MySQL.com) or for example by running Docker
      MySQL containers on your machine e.g. from official MySQL
      Docker images.
    - You can use either MySQL version 5.x or version 8.x (but
      please state which you have used in your solution).
    - You should be familiar with loading a MySQL dump file to
      build a schema containing data tables that you will work
      from to create your challenge solution. The sample data
      supplied for the challenge is only a few hundred rows.
    - You will be required to build and run SQL queries against
      the database to build your solution. If you prefer to use
      a graphical interface rather than the command line MySQL
      client, MySQL Workbench is an option.
    - NOTE: Once you begin the challenge the countdown will start
      and your code challenge files will download.

### CPP - Incomplete sequences (C++)
    - Before taking the challenge, please make sure you have
      working C++ compiler and that you will be able to
      extract/create ZIP archive for the purpose of the
      challenge.
    - Using C++ standard library (STL) is allowed.
    - Using C++11/C++14/C++17 is allowed.
    - You don’t need any specific IDE.
    - Please, do not rely on any non-standard additional
      libraries (like boost). The code should compile on any
      machine using any major C++ compiler (g++/msvc/few more)
      without additional plugins or additional packages
      downloaded from internet.

    - You will be provided some example code, instructions on how
      to compile those and some tools helpful for testing.
    - It is allowed to add additional files, functions and
      classes.
    - The testing code should stay as is provided - solution
      implementation will be tested using it.
    - It is allowed to use custom makefiles (make/cmake) or to
      add project files created by common IDEs.

    - Please make sure you know how to use _std::vector_ and
      _std::string_ from STL. Documentation can be found on
      cppreference.com.
    - Note: No matter what compiler/IDE you use, please do not
      expect that it will be compiled in exactly the same way you
      do it (using the same compiler/version). You don’t have to
      (but you can, if you like) add any makefiles/project files
      you created to compile the code on your machine. Our
      reviewers can prepare their programming environment to
      compile your code using their tools, but they will not
      change your code to make it compile.
