haskell history
    1930 Alonso Church 
        lambda calculus - theory of functions

    1950 John McCarthy 
        functional but imperative variable assignments

    1960 Peter Landis 
        I(Y)SWIM, pure functional language, no assignments

    1970 John Baccus 
        Fortran founder, created "FP", higher order functions
        reasoning about programs

    1970 Rober Milner
        ML, first MODERN functional language. 
        originally scripting language for mathematical proofs
        (supplied boiler plate for proofs)
        type inference - compiler infers type  
        polymorphic (generic) types 
        - list of "t" with string, numerics

    1970's 80's David Turner
        Cecil (mother of haskell), 
        Miranda, 'lazy' functional languages

    1987 Various
        Researchers develops standard (functional) language
        to experiment with new type systems.
        "petri dish for programming language research"
