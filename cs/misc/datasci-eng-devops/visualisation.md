
Data types and visual maps
    * We need to _map_ data sets to visual attributes 
    * This is known as data encoding

Data Types:
    1. _Nominal_
        labels/names - e.g. Fruits: apples, oranges
        operations: =, !=

    2. _Ordinal_ 
        Ordered - Quality of meet: Grade A, AA, AAA 
        there is an implicit order
        operations: =, !=, >, <, >=, <=


    3. _Quantitative_ - Interval
        zero point is arbitrary
        e.g. dates, latitude
        like a geometric point, can't be compared directly
        only intervals can be compared
        operations: minus, =, !=, >, <, >=, <=
                    measure distances or spans

    4. _Quantitative_ - Ratio
        zero point is fixed
        Physical measurements: length, mass
        counts and amounts
        like a geometric vector, the origin is meaningful
        operations: divide, minus, =, !=, >, <, >=, <=
                    measure ratios or proportions
