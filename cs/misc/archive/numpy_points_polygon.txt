numpy points polygon

Test whether a point is inside a polygon

The nxutils provides two high-performance methods: for a single point
use pnpoly() and for an array of points use points_inside_poly(). For
a discussion of the implementation see pnpoly.

In [25]: import numpy as np

In [26]: import matplotlib.nxutils as nx

In [27]: verts = np.array([ [0,0], [0, 1], [1, 1], [1,0]], float)

In [28]: nx.pnpoly( 0.5, 0.5, verts)
Out[28]: 1

In [29]: nx.pnpoly( 0.5, 1.5, verts)
Out[29]: 0
