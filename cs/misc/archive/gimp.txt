gimp

useful plugins
	http://registry.gimp.org
	BIMP: Batch Image Manipulation Plugin
	Noise Generator
	Layer via Copy/Cut
	Install to:
	c:\Program Files\GIMP 2\lib\gimp\2.0\plugins

zoom
	+ and - keys
	1 zooms to 100%
	[] increase/decrease brush size
	(ie. one picture pixel per one monitor pixel)

pan around document
	hold SPACEBAR

HSB
	Hue, Saturation, Brightness

HSV
	Hue, Saturation, Vibrance

Color Levels
	"hidden gem"
	Tools - Color Tools - Levels
	Auto command

Color Curves
	More control than Color Levels
	Like 255 dimmer switches
	click on a point and raise or lower it
	Want "S Curve"

(Selective) Guassian Blur
	It may launch as a separate window.
	Duplicate a layer
	Blur the whole top layer
	Then apply mask to top layer
	which allows some of the blurring
	through to the buttom

Unsharp Mask
	It may launch as a separate window.


Liquid Rescale
	Have to download plugin
	convert landscape to portrait

Cage Transform
	magic! A little wooden dummy,
	Define a cage around the dummy body
	then select an arm, a leg etc
	and move it. It then redraws the
	dummy in the new position!

Paths
	tool for drawing vector shapes...
	Can then be used for making selections,
	press "control" to enter edit mode

Dodge Burn
	Lighten Darken a photo

Blur Sharpen
	Then use layer masks and opacity

Clone tool
	filled in old torn photograph
	set sample point first
	using CONTROL CLICK
	also perspective clone tool
	where you setup vanishing point first

using layers
	setup a blur layer
	AND THEN SET OPACITY TO 50%
	what that does when combined
	with the layer below is produce
	a dreamy effect...


Drop shadow
	filter - light and shadow
	creates shadow in its own layer
	can group layers together
