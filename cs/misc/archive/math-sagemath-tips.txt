### copy.deepcopy
    1. deep copies return **new** objects in memory
        current list in memory:
        [a,b,c,d]

        shallow copy
        [a,b,c,d]

        deep copy
        (different objects in memory)
        [a',b',c',d']

    2. to ensure its a deep copy:
        import copy
        `new_L = copy.deepcopy (L) `


### pitfall:
    mutability in shallow/deep copy

    `m = [[]] * 5`
        DOESNT return 5 INDEPENDENT lists,
        but takes the same object and
        returns it 5 times.
        so it is a "shallow copy"

    e.g. `m[0].append[5]`
        will return [[5], [5], [5], [5], [5]]
        and NOT     [[5], [0], [0], [0], [0]]

    so when creating lists of
    any MUTABLE type object do:
        `[ [] for x in range (5) ] `

### Sage for undergrads
    1. Sage IS case sensitive except for:
        i   I
        n() N()
        True true
        False false

    2. exponential function
        e exp

    3. natural log
        > log         is always the natural log
        > log(_, 10)  is log to the base 10
        > log(_, 2)   is log to the base 2

    4. get all roots!
        sqrt(4, all=true)
        sqrt(-4, all=true)

    5. matrices
        A = matrix(rows, cols, [a,long,list,one,after,the,other]  )
        A = matrix([row1],[row2],[row3])
        reduced echelon: `A.RREF()`
        matrices are zero based : `A[0][0]`

    6. defining functions:
        f(x)    = x^2 + 3
        g(x)    = sqrt(x)
        h(x)    = f(g(x))
        f(x,y)  = x^4 + y^4

    7. infinity symbol! (two "o"s!)
        oo, -oo

    8. solving equations:
        assume(x>1)

    9. plotting:
        p = plot(...)
        p.save("myplot.eps")
        plot (f..., (x,-2,2), detect-poles=True, ymin=, ymax= )

# example
    A fun example, for teaching math to younger folks,
    is to play with patterns.

    A super-easy pattern is
    `1 + 3 + 5 + 7 + 9 + ... + whatever = (whatever+1)^2 / 4`

    ...but that super-easy pattern leads to the
    Fermat factorization algorithm.

    One of my favorites was
    `1^3 + 2^3 + 3^3 + 4^3 + 5^3 + ... + (whatever)^3 = `
    `(1 + 2 + 3 + 4 + ... + whatever)^2`

    The Sage **sum** command is very useful for these.
    Enjoy! Greg

# comment
    p.s. The use of "whatever" is strategic. Many young people associate
    "**x**" with homework, tests, stress, etc which is a shame
