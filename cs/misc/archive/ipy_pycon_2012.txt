Commands V Variables
	cd ~ 	
	works normally
	
	cd = 123 	
	now cd is a normal python variable

run -i simple_script.py
	run the screen in the interactive namespace, not in an empty namespace!

run -n simple_script.py
	normally it thinks name == "__main__", but if you set "-n" then the "__main__" part doesnt execute. A bit like importing the file really

run -t
run -p
	run a script under the time and under the python profiler.

run -d
	run under the ipdb debugger(enhanced version of pdb). Press "c" for continue

notebook limitation
	doesnt currently support raw_input

qtconsole copy
	you can copy or "raw copy", normaly "copy" strips away the ... bits

shell scripting inside ipython
	!echo "hello world" - use the exlamation mark symbol
	$i - single dollar - python variables interpolated into the shell
	$$HOME - double dollar - gives you a full shell variable
	do shell scripting from iPython

Assign shell output to a python variable
	a = !ls
	now "a" is a list object....!

iPython "scripts"
	you can save all your ipython commands in a file."ipy" and then run it by calling ipython...??? And all the magics, shell stuff etc gets run properly

debugging
	script crashes... just type "debug", then use !print to show variable values
