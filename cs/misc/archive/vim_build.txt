original helpful article

    Sometimes user does not have control over Linux-like system but still would
    like to have a latest version or VIM in use. Such setup can be still reached,
    but not suggested, with local install of the software. However, there is a
    small trick with installation.

    didnt need this ( but did need it on UBUNTU)
        1. Install latest nurses library. Most of the systems have this lib pre-
        installed. Nevertheless, we want user to have the most up-to-date install. For
        this, follow next steps:

        mkdir ~/Downloads
        cd ~/Downloads
        wget http://ftp.gnu.org/gnu/ncurses/ncurses-5.9.tar.gz
        tar -xzf ncurses-5.9.tar.gz
        cd ncurses-5.9
        mkdir ~/Applications
        ./configure --prefix=$HOME/Applications/ncurses

    2. Install vim (main step!)
        cd ~/Downloads
        hg clone https://vim.googlecode.com/hg/ vim
        export LDFLAGS="-L$HOME/Applications/ncurses/lib"
        cd vim

        ./configure --enable-gui=no --without-x -with-features=huge --prefix=$HOME/Applications/vim --with-tlib=ncurses
        or with python
        ./configure --enable-gui=no --without-x -with-features=huge --enable-pythoninterp --prefix=$HOME/ef_apps/vim --with-tlib=ncurses

        make
        make install

    3. Make vim accessible system-wide: (add to ~/.bashrc)
        export VIM_DIR=$HOME/Applications/vim
        export VIMRUNTIME=$VIM_DIR/share/vim/vim73
        export EDITOR=vim
        export PATH=$VIM_DIR/bin:$PATH
