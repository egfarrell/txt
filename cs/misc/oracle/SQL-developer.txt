### Oracle SQL Developer

### data modelling
	- In SQL Developer 3, it's pretty straightforward (they could've made it
	easier). Go to View -> Data Modeler -> Browser. The browser will show
	up as one of the tabs along the left-hand side. Click on the Browser
	tab, expand the design (probably called 'Untitled_1'), right-click
	Relational Models and select 'New Relational Model'. Then just drag
	the tables you want onto the model.

### compare schemas
	Tools -> Database Diff

### set date format
    From SQL Developer, open menu Tools >> Preferences.
    From the Preferences dialog, select Database >> NLS Parameters from the left panel.
    From the list of NLS parameters, enter DD-MON-RR HH24:MI:SS into the Date Format field.

	- tick "Line" checkbox

### Debugger – Start Debugging Option
    - Set this to ‘Step Over.’
    - allows you to start and run a debug session without
      breakpoints.
    - If you leave it at the default, starting a debug session
      will appear to ‘not work.’ - SQL Developer will enter debug
      mode and run until it finds a breakpoint, breaking
      condition, or exception. If you have none, it will execute
      to the end of your program.
