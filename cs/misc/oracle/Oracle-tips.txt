### CURSORS
    - 5 types
        - implicit cursors
        - explicit cursors
        - cursor variables
        - cursor expressions
        - dynamic sql queries


    - SGA: System Global Area
        - holds data specified by an SQL statement

    - static SQL
        - if fully fixed or specified at time code is compiled

    - Dynamic SQL
        - constructed at runtime and then executed.
        - use DBMS_SQL or native dynamic SQL

    - Result Set
        - set of rows identified by the DB as fulfilling the
          request of some SQL statement.
        - Cached in the SGA to improve performance when accessing
          or modifying this data.

    - Current row:
        - a pointer into the result set

    - Implicit cursor
        - created everytime you run a DML statement
        - (insert, update, merge, delete)
        - created by SELECT INTO (which returns a single row
          directly into a PLSQL data structure)
        - implicit because DB auto handles many of the cursor
          related operations
        - (e.g. allocating cursor, opening, fetching)

    - Explicit cursor
        - a `select` where you declare a cursor
        - must explicitly perform open, fetching, close etc
        - Used when retriving multiple rows using static SQL

    - cursor variable
        - variable you declare which references or points to
          a cursor object.
        - A true variable
        - can change its value (i.e. the cursor it points to) as
          the program executes.
        - Can be passed as parameter.
        - Useful when passing result set info to another
          environment (Java or VB...)

### CURSOR attributes
    - cursor_name%attribute_name

    - %FOUND
        - true  if record fetched successfully
        - false otherwise

    - %NOTFOUND
        - true  if record NOT fetched successfully
        - false otherwise

    - %ROWCOUNT
        - number:
        - # records fetched from cursor at that point in time

    - %ISOPEN
        - 'true'      cursor is open
        - 'false'     otherwise

    - %BULK_ROWCOUNT
        - number: # records modified by FORALL for each
          collection element

    - %BULK_EXCEPTIONS
        - exception information
        - for rows modified by FORALL
        - for each collection element

    - implicit cursors
        - cursor name hardcoded as "SQL"
        - e.g. SQL%NOTFOUND

    - ### open_mode 'wb' for windows!
        - handy tip!!
        - Yesterday a collegue found a bug in my PL/SQL packages
          for operating system interaction "OS_COMMAND".
        - The error is in the LOB_WRITER_PLSQL package and occurs
          only on Windows platforms: Binary files are not written
          correctly into the file system - the resulting files
          are corrupt.
        - The reason is the `FOPEN` in the UTL_FILE package. If
          you want to write binary content on windows platforms
          make sure that you provide the OPEN_MODE 'wb' and not
          just 'w'.
        - On Unix/Linux platforms this does not make
          a difference. The newest version 0.5.2 corrects this.
          Only the package LOB_WRITER_PLSQL is affected by the
          "patch".

### Triggers
    - 5 events can have triggers

    1. DML statements
        - Insert, update or delete statements perform validation,
          set default values, audit changes, disallow certain DML
          operations

    2. DDL statements
        - whenever DDL is executed - e.g. table created perform
          auditing and prevent certain DDL operations

    3. Database events
        - whenever database starts/shuts, user logs on/off, an
          Oracle error occurs. Provides ability to track activity
          in the database.

    4. INSTEAD OF (views)
        - control operations on VIEWS not tables. alternatives to
          DML triggers they fire when inserts, updates, deletes
          about to occur Your code specifies what to do in place
          of these DML actions. Can make non-updatable views
          updatable. Can lock updatable views

    5. Suspended Statements
        - Statements experiencing a lack of tablespace or quota
          enter a suspended state until problem fixed. 
        - Triggers can be added to alert someone, or fix the
          problem.
