### how to compile
    - standard
        > g++ -o hello main.cpp -std=c++11
    - old g++
        > g++ -o hello main.cpp -std=c++0x
    - for debugging
        > g++ -g myprog.cpp

### struct packing
    declare variables in a struct from largest to smallest.
    It reduces the struct size and helps the compiler because
    certain datatypes starting on a memory boundary.
    e.g.
    ...
        double myvar1
        double myvar2
        double myvar3
        int myint1
        int myint2
        int myint3
        char mychar1
        bool mybool1
        bool mybool2
    ...
    or use #pragma directive (less portable)
    or use "alignas"
