UMGC and USMx's Bioinformatics MicroMasters
https://www.edx.org/micromasters/usmx-umgc-bioinformatics


### 3 courses
    - ./micromasters-UMGC/Proteins.txt
            - Proteins Alignment Analysis Structure
            - Learn about proteins and the role structure plays
              in their function. Learn how to analyze and align
              protein sequences.


    - ./micromasters-UMGC/Statistical-Analysis.txt
            - Statistical Analysis in Bioinformatics
            - Learn R programming to analyze biological big data
              to locate genes, perform simulations, and gauge the
              effect of specific markers.


    - ./micromasters-UMGC/DNA-Sequences.txt
            - DNA Sequences Alignments and Analysis
            - Learn how to align and analyze DNA sequences using
              web and software based tools to find mutations and
              other anomalies in genes and genomic sequences.
