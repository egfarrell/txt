### Study notes: Second brain (agent accessible notes)
    - Nate B Jones
    - https://www.youtube.com/watch?v=2JiMmye2ezg
    1. "Open brain" is a personal knowledge system built as
    a real database, not a notes app, txt file, or Notion.
    2. Stores your thoughts in a PostgreSQL database. Each
    thought is saved as structured data (text, embedding,
    metadata).
    3. Each thought is converted into a vector embedding
    (numerical representation of meaning), enabling semantic
    search rather than keyword search.
    4. Semantic search allows AI to retrieve relevant memories by
    meaning, even if the exact words don’t match.
    5. Supabase is used as the backend to manage the Postgres
    database and automatically generate embeddings and store
    data.
    6. An MCP server acts as a universal access layer so any AI
    (ChatGPT, agents, etc.) can read/ write to same memory.
    7. The system separates capture and retrieval:
       - capture: input text → embedding → stored in Postgres
       - retrieval: AI queries MCP server → semantic search
         → returns relevant memories
    8. Unlike traditional note apps, this system is designed for
    machine readability first, not human browsing.
    9. This creates persistent, shared memory across all AI
    tools, so agents never start from zero and always have full
    context.
    10. The core architecture is: Postgres database + vector
    embeddings + Supabase backend + MCP server = universal
    AI-readable personal memory.
