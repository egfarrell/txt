# Pearson product-moment correlation coefficient (r)
    r = the degree by which X and Y vary together (covary)
    relative to the degree in which X and Y vary independently.
    i.e. a ratio of covariance to variance

    r = (covariance(X & Y)) / (variance of X & Y).
    This is for continuous X and Y variables.


# Sum of Cross Products (SP)
    In Lboro I think this was SSxy
    For each sample subject
    calculate deviation score of both X and Y
        (X - Mx)
        (Y - My)
    multiply the 2 deviation scores together (Cross Product)
        (X - Mx) * (Y - My)
    Then sum these cross products
        SP = ∑(Cross Products) = ∑((X-Mx) * (Y-My))

# Calculate "r"
    can calculate "r" in terms of DEVIATION SCORES:
        `r = SPxy / Sqrt(SSx * SSy)`

    See how SSx, SSy is similar to SPxy:
        `SSx = ∑(X-Mx)^2 = ∑(X-Mx) * (X-Mx)`
        `SSy = ∑(y-My)^2 = ∑(y-My) * (y-My)`

    So:
        `r = ∑((X-Mx) * (Y-My)) / sqrt(∑(X-Mx)^2 * ∑(y-My)^2)`

# Calculate "r" using Z-SCORES
    - `r = ∑(ZxZy) / N`
    - basically if you expand Z it all works out like the other
      formula above

# Variance and Covariance
    Variance = Mean Squares (MS) = (SS / N)
    Covariance = COV = (SP / N)

    Correlation is standardised COV
    so the output value is between -1 and +1

# Reliability of a correlation (P-values)
    Using another sample and will I get the same "r"?
    (ie. within the bounds of sampling error is "r" reliable)
    Thats a tough question. Different approaches.
    One approach is to use NHST

# NHST of "r"
    Null Hypothesis Significance testing
    Looking at probability of a correlation,
    at the level of samples.
        H0 --> null hypothesis. assume no correlation between X and Y. r=0
        Ha --> alternative hypothesis. r<>0

# P-values  
    GIVEN the null hypothesis (H0) then
    -------------------------
        p = conditional probability(Data|H0)

        if (p < 0.05)
            hey this is significant,
            reject the null hypothesis

# P-value important point:

    * "p" is the probability of getting this data/outcome
      (GIVEN the Null hypothesis)

    * "p" is NOT the probability of the Null Hypothesis
      (given this data/outcome)

    But statisticians often want to flip that around:
    they say I don't want to know the probability of an
    outcome, I want to know the probability of a hypothesis
    (given this data). This is the _Bayesian_ approach.


# Types of Errors:

                  Decide to Retain H0    Decide to Reject H0
                  -------------------    -------------------
H0 really true:   Well Done              Type I Error (False Alarm)
H0 really false:  Type II Error (Miss)   Well done


# Probability of making an Error:

                  Decide to Retain H0    Decide to Reject H0
                  -------------------    -------------------
H0 really true:   p = (1-α)              p = α (False Alarm)
H0 really false:  p = β (1-POWER)        p = (1 - β) POWER

# Reliability

    * Classical Test Theory ("True Score Theory")
        Raw scores (X) subject to bias and chance error In
        a perfect world we'd obtain a "true score" 
        `X = (true score) + (bias)  + (error)`

    * When is a measure X reliabile?
        X is reliable when when it approaches the true score
        Problem is, we don't know the true score, so we
        ESTIMATE the reliability

    * Methods to estimate Reliability 
    ("wand" which runs a bit high) 
        Test / ReTest
            measure everyone twice with "wand" - (X1), (X2)
            correlation analysis between X1 and X2 is
            a reliability estimate BUT! if theres a uniform
            bias this test/retest wont find it! cos both X1
            and X2 will both be biased

    * Parallel Tests
        measure everyone with "wand" (X1) and with
        "thermometer" (X2) Run correlation, if high then
        we have some reliability and bias of the wand
        will be revealed

    * Inter-item estimates
        most common in social sciences (other 2 methods
        expensive!) e.g. 20 item survey to measure
        extraversion RANDOMLY select 10 items to get
        subset A (X1) The other 10 items become subset
        B (X2) The correlation between X1 and X2 is
        a reliability measure

    The process of defining a construct to make it

# Assess construct validity
    Construct: "verbal ability" in Children
    Operationalise: Use a vocabulary test

    Content Validity
        Does test consist of words children should know

    Convergent Validity
        Does this test correlate (converge) with other established
        measures of verbal ability e.g. reading comprehension

    Divergent Validity
        Does the test converge LESS WELL with tests of a different ability
        e.g. spatial reasoning

    Nomological Validity
        Are test scores consistent with more general theories outside this
        particular domain e.g. theories of child development and neuroscience.
        e.g. a child with neural damage to regions associated with language
        development should score lower on the test
