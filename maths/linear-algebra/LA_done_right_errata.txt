Linear Algebra Done Right
First and Second Printings of the Second Edition, Errata

I tried hard to make Linear Algebra Done Right error-free, but
spotting mistakes in one's own writing can be difficult in
a book-length work. Errors in the first and second printings of the
second edition that I know about are listed below. All these errors
were corrected in the third edition. If you notice additional errors
in the book or have suggestions for improvements, please let me know
(linear@axler.net).

On page 5, second line below 1.1, "an list" should be "a list". 

On page 18, second line from the bottom, "with equation" should be "with the equation". 

On page 28, second line from bottom, "spanned B" should be "spanned V". 

On page 65, line 9, "q_2" should be "q_1". 

On page 81, line 9 of the proof of 5.10, "coefficients a1, ..., am" should be ""coefficients a1, ..., an". 

On page 87, last line of text, "if and only" should be "if and only if". 

On page 88, line 21, "with respect to some operator" should be "with respect to some basis". 

On page 103, in the figure, "lambda v" should be "av". 

On page 107, four lines above 6.17, "a_m" should be "a_n". 

On page 108, in the marginal note, "Dutch" should be "Danish". 

On page 144, line 5, "conjugate" should be "transpose". 

On page 151, line 12 from the bottom, "1-by-1"" should be "1-by-1 matrix". 

On page 154, last line, "S2u" should be "S2w". 

On page 185, the four summations starting with "r=0" should start with "r=1".
