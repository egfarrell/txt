### Heaviside
    - $MY_NOTES/physics/EM/Heaviside-maverick.txt
    - Hamilton thought that his symbolic scheme of opposite
      rotations (`ij = k` but `ji = −k`) would be just the thing
      to represent physical relationships like that between
      electricity and magnetism;
        - E.g., it was well known that if you reversed the linear
          direction of the current in a straight wire the
          circular magnetic field around it would also reverse,
          but in a rotatory sense, from, say, clockwise to
          anticlockwise.
        - But there was a flaw in the scheme. He used `i`, `j`
          and `k` to represent `90 ◦` rotations about three
          mutually perpendicular axes and the _SAME SYMBOLS_ to
          represent unit vectors in the `x`, `y` and `z`
          directions.
        - This led to some strange properties:
            - E.g., the square of a vector was negative.
            - Heaviside and Gibbs overcame the difficulty by
              distinguishing between so-called vector and scalar
              products.
        - In modern notation bold-faced letters `i`, `j` and `k`
          represent the three unit vectors, and rotations are not
          defined not by `i`, `j` and `k` themselves but by their
          vector products:
            - i×j = k
            - j×k = i
            - k×i = j
            - i×i = j×j = k×k = 0
        - whereas, in the scalar products:
            - i.i = j.j = k.k = 1 and
            - i.j = j.k = k.i = 0
        - Problem solved – the square of a vector was no longer
          negative – but Tait saw this as a desecration of
          Hamilton's beautiful scheme

### the Outer Product

- Yes, Example 1 is an example of the outer product of two
  vectors. The outer product of a column vector `u` and a row
  vector `v` produces a matrix. Specifically, if:

- `u = [[u1], [u2]]`
- `v = [v1, v2]`

Then their outer product `u * v` is:

```
u * v = [[u1 * v1, u1 * v2],
         [u2 * v1, u2 * v2]]
```

Using the specific values from Example 1:

- `u = [[1], [3]]`
- `v = [2, 4]`

The outer product is:

```
[[1], [3]] * [2, 4] = [[1 * 2, 1 * 4],
                       [3 * 2, 3 * 4]]
                   = [[2, 4],
                      [6, 12]]
```

### Use and Significance of the Outer Product

    1. Constructing Matrices: The outer product is used to
       construct matrices from vectors, which is particularly
       useful in tensor algebra and various applications in
       linear algebra.

    2. Tensor Product: The outer product is a special case of the
       tensor product for vectors, which is essential in fields
       like QM, where the state of a system is represented as
       a tensor product of individual states.

    3. Representation of Linear Transformations: Outer products
       can represent linear transformations. E.g. in ML, outer
       products are used in neural networks to represent the
       weight matrices that map input vectors to output vectors.

    4. Covariance Matrices: In statistics, the outer product of
       a random vector with itself is used to form covariance
       matrices, which are crucial in understanding the variance
       and relationships between variables.

    5. Rank-1 Matrices: The outer product always results in
       a rank-1 matrix, meaning it captures the simplest form of
       a matrix that still maintains its structure, often used in
       low-rank approximations and data compression.

    6. Geometric Interpretation: Geometrically, the outer product
       can be viewed as creating a grid or area in space defined
       by the vectors, useful in physics and engineering for
       defining planes or surfaces in multidimensional spaces.

    - The outer product is a powerful tool in linear algebra that
      allows for the extension of vector operations to more
      complex matrix structures, making it essential for various
      applications in science and engineering.

### Interesting: zero vector perpendicular to every v...
    - Theorem:
        - The vectors `(x1, x2)` and `(y1, y2)` are perpendicular
          to each other if and only if `x1 • y1 + x2 • y2 = 0`.
    - Proof.
        - Notice if one, or both, of the two vectors is the zero
          vector, then `x1 • y1 + x2 • y2 = 0`.
        - For this reason we define the zero vector as being
          PERPENDICULAR to every vector. (!)
        - Another special case is when the two vectors lie on the
          same line through the origin; ie, when `y1 = t • x1`
          and y2 = t • x2 for some real number t.
        - In this case, the vectors are perpendicular iff one of
          them is the zero vector, which happens if and only if
          t • x1 = t • x2 = 0.
        - Thus, the theorem holds in this case. Now assume that
          the two vectors do not lie on the same line through the
          origin.
        - Theorem continues...

### vectors as functions
    - Defining the vector as a function is just a mathematical
      formalism, one of the several possible rigorous ways to
      define it:

    - The ordered list
        - `x = (x_1, ... ,x_n) ` of scalars in a field F can be
          defined as the function:
        - `x:{1, ..., n} → F`

    - For example, the vector
        - `x = (5,6,7) `
    - is the function
        - `x: {1,2,3} -> {5,6,7} `
    - ie, from the
        - index set `{1,2,3}`
        - to the real numbers `ℝ`
        - (specifically to the real numbers 5, 6, 7)
    We have
        `x(1) = 5 = x_1, `
        `x(2) = 6 = x_2, `
        `x(3) = 7 = x_3. `

    key point:
        - The ordered list of values that you usually think of as
          a vector is really a _set of elements in the codomain_
          of the function that defines the vector.

    - The order of the ordered list comes from the order of the
      underlying natural numbers in the domain.

    - Of course, we aren't limited to using the natural numbers
      as the _index set_. We can use pretty much an arbitrary
      set.

### (Affine Space) v (Vector Space)
    - Consider an infinite sheet (of idealised paper, if you
      like). If it is blank, then there is absolutely no way to
      distinguish between any two points on the sheet.
      Nonetheless, if you do have two points on the sheet, you
      can measure the distance between them.
        - And if theres a uniform magnetic field parallel to
          the sheet, then you can even measure the bearing from
          one point to another.

    - Thus, given any point `P` on the sheet, you can uniquely
        - describe every other point on the sheet by its distance
          and bearing from P;
        - and conversely, given any distance and bearing, there
          is a point with that distance and bearing from P.

    - This is the situation that the notion of
      a 2-dimensional _affine space_ is an abstraction of.

    - Now suppose we have marked a point `O` on the sheet.
        - Then we can "add" points P and Q on the sheet by
          drawing the usual parallelogram diagram.
        - The result P+Q of the "addition" depends on the choice
          of O (and, of course, P and Q), but nothing else.

    - This is what the notion of a 2-dimensional _vector
      space_ is an abstraction of.

### vector {components} v {coordinates}
    - The vector space `F^n` is the set of all n-tuples of
      elements of F.
    - So given a vector (a1,…,an) ∈ F^n, we can define the i'th
      component of (a1,…,an) to be `a_i`.
    - To define the coordinate vector of a vector, we need to fix
      an ordered basis β={v1,…,vn}. For any v∈F^n, by definition,
      we can find scalars c1,…,cn such that

    v=c1v1+⋯+cnvn

    We define the coordinate vector of v with respect to β to be

    [v]β=(c1,…,cn)

    - Note that if β is the standard basis, we have [v]β=v for
      any v∈F^n.
    - Coordinate vectors are always defined for vectors in
      a vector space with an ordered basis.
    - However, components are only defined in F^n.
