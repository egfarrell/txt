In the context of the principle of least action (or Fermat’s principle for light), an extremal path is one for which small variations of the path do not change the quantity of interest (time, action, etc.) to first order.

Here is the idea in plain language.
1. Consider a family of nearby paths

Imagine the true path x(t). Now consider a slightly different path
x(t) → x(t) + ε η(t), where ε is a small number and η(t) is any smooth “wiggle’’ that vanishes at the endpoints.

For each ε you get a time T(ε) (in Fermat) or an action S(ε) (in mechanics).
2. What “no first-order difference’’ means

Expand T(ε) for small ε:

T(ε) = T(0) + ε T′(0) + ½ ε² T″(0) + …

The term ε T′(0) is the first-order change.

An extremal path is defined by the condition:

T′(0) = 0.

This is exactly the meaning of “no first-order difference”.
If you wiggle the path slightly, the leading change in travel time vanishes: the time changes only at order ε² or higher.
3. Why this defines the actual path

If T′(0) ≠ 0, then by choosing ε positive or negative you can make T(ε) slightly smaller or larger. That would mean the original path was not special — you could improve it with an infinitesimal tweak.

But if T′(0) = 0, the original path is locally optimal (minimum, maximum, or saddle). You cannot beat it with infinitesimal adjustments.
4. Geometric analogy

Think of a function f(x). At a minimum, small shifts x → x + ε produce

f(x + ε) = f(x) + 0·ε + ½ f″(x) ε² + …

The absence of a first-order term is what you normally call a vanishing slope.
The PLA generalizes this idea from functions to functionals (things whose input is a function or path).
5. Fermat’s principle example

For light in a medium, the travel time functional is

T[path] = ∫ n(x) |dx/ds| ds

The true optical path satisfies δT = 0, meaning the first-order variation of T is zero. This is what Fermat meant when he said light follows the path that does not differ in time to first order compared with nearby paths.
Summary

“Extremal path’’ = a path for which small variations produce no first-order change in the time (or action).
Mathematically this is the condition δS = 0 or δT = 0.
Physically it means the actual path cannot be improved by infinitesimal tweaks.

Great questions. Both get at the heart of what the δ-notation really means.
1. Is T′(0) = 0 just another way to write δT = 0?

Yes — conceptually they mean the same thing.

Take a path x(t). Consider a nearby path x(t) + ε η(t). This gives you a 1-parameter family of values T(ε). Then:

T′(0) is the derivative of T with respect to ε at ε = 0.

δT is defined as the first-order change of T under this infinitesimal variation.

So in the standard setup:

δT = T′(0).

The symbol δ does not mean an ordinary derivative with respect to time or space. It means: “change T when the entire path is nudged by a small amount.’’ It is a differential, but a differential in function space. It is a directional derivative of the functional along the direction η(t).

So the equivalence is:

δT = 0 ⇔ T′(0) = 0.
2. Does “first-order difference’’ come from doing a Taylor expansion in ε?

Exactly. This is the whole mathematical foundation of variational calculus.

When you vary the path by ε η(t), you look at:

T(ε) = T(0) + ε T′(0) + ½ ε² T″(0) + …

The term ε T′(0) is the first-order piece.
The variational principle demands that this term vanish for all allowed η(t).

So:

δT = 0 means the coefficient of ε in the Taylor expansion is zero.

That’s why one talks about “no first-order difference’’ — the action or travel time doesn’t change linearly when you apply an infinitesimal deformation of the path.
A concise conceptual picture

• A functional like T[path] behaves like a function whose input is a whole curve.
• When you “wiggle’’ the curve, the change in T is expanded in ε.
• The δ notation captures the linear (first-order) term in this expansion.
• Setting δT = 0 means you’re at an extremum in this infinite-dimensional space of paths.

The short story is: the δ-notation evolved historically to distinguish variations (changes in a whole function or path) from ordinary differentials (changes in a variable like x or t). It was introduced by Euler and Lagrange in the 18th century when they were inventing the calculus of variations.

Here is the intuitive idea behind the choice of the symbol.
1. Ordinary differentials vs. variations

In standard calculus you use dx, dy, dF to mean small changes in numbers or in the inputs of an ordinary function F(x).

But in the calculus of variations the object you change is not a number but an entire function x(t). Euler realized he could not recycle dx or dF, because that would be confused with the usual differential of F(x) with respect to x or t.

So he introduced a distinct symbol to mark “this is not an ordinary differential; this is a variation of a whole curve.”

That symbol became δ.
2. What δ was intended to convey

δx(t) means the “allowed wiggle’’ of the function x(t).
δT means the resulting first-order change in the functional T[x(t)].

Crucially, δ is linear (δ of a sum is the sum of δ’s) and operates only on the quantity whose variation is being considered. It behaves like a differential operator, but one whose domain is function space.

So the meaning is:

δT = first-order change of T under x(t) → x(t) + ε η(t).

This makes δ easy to manipulate algebraically and separates it clearly from dx and dT of ordinary calculus.
3. Why the particular symbol δ?

There is no deep mathematical necessity — it is mostly historical convention, originating with Euler and Lagrange. They wanted:

• a symbol distinct from d, to avoid confusion
• something suggestive of “difference’’ or “deviation’’
• something easy to write alongside integrals

δ was a natural choice because Δ (capital delta) already meant a finite difference, and δ intuitively evokes an infinitesimal difference but of a different kind from dx.

So the hierarchy became:

Δx = finite difference
δx = infinitesimal variation of a function
dx = infinitesimal differential of a variable
4. Modern interpretation

Mathematically, δ corresponds to taking a directional derivative of a functional in an infinite-dimensional space. But physicists keep the δ symbol because:

• it mirrors historical usage
• it remains intuitive
• δT = 0 is an elegant way to express “no first-order change”
