### Congruence:
    - Convention: We always want to give a _positive_ remainder
      when checking for congruence of a negative number.
        - ie we dont say: `-8 ≡ -3 (mod 5)`
        -    we say:      `-8 ≡ 2  (mod 5)`
        - (just keep adding 5's to -3 until we get back into the
          positive numbers)


### Congruent: succinct statement
    - Two numbers say `a` and `b` are congruent `modulo n` if and
      only if there exists an integer `k` such that `a = b + kn`.
    - This means that `a - b = kn` which means that the
      difference of the two numbers is a multiple of `n`.
    - ALTERNATIVELY: the positive remainders of `a` and `b` when
      divided by `n` are equal.

### multiplicative inverse (the numbers must be coprime!)
    - some numbers don't have a multiplicative inverse
    - `3v ≡ 1 (mod 9)`
    - this would imply: `3v = 1 + 9k` (ie we write the congruence
      as an equation)
    - but 3 will never divide evenly into the RHS. (because of
      the `1 +...`
    - the problem is 3 and 9 share a common factor: `3`
    - So if you want a multiplicative inverse, you need a number
      and a modulus that only have a common factor of `1`
    - Another way of saying two numbers only have a common factor
      `1` is they are: _coprime_

    - Bezouts identity says if two numbers have a highest common
      factor of 1 we can write:
        - `av + 9w = 1`
    - so lets rewrite this as a congruence equation:
        - `av = 1 - 9w`
    - which is the same as:
        - `av ≡ 1 (mod 9)`
    - so, `v` is a multiplicative inverse of `a` modulo 9.

### Summary: multiplicative inverese
    - If the integers `a` and `n` are coprime, then there is
      a multiplicative inverse of a modulo `n`.
    - If `a` and `n` are not coprime, then there is NO
      multiplicative inverse of a modulo `n`.

### More multiplicative inverse:
    - whats so importat about "_coprime_" all the time? 
    - Beause if two numbers are coprime you can get
      a multiplicative inverse... 
    - (and later: if you can get a multiplicative inverse you can
      solve a linear congruence.)
    - when asked to give a multiplicative inverse, its usually
      clearest to give the _least residue_.

### Method
    - So far, you’ve found multiplicative inverses modulo `n` by
      trying the values `1, 2, 3, ..., n − 1` one by one.
    - This method can, however, be very time consuming if `n` is
      large! 
    - In the next example, you’ll see how to find multiplicative
      inverses by using Euclid’s algorithm and backwards
      substitution.


### Linear Congruences
    - Solving linear congruences when `a` and `n` are coprime:
    - If `a` and `n` are coprime, then the linear congruence
        - `ax ≡ b (mod n)` has solutions.
    - The solutions are given by `x ≡ vb (mod n)`
        - where `v` is any mult. inverse of `a` modulo `n`
    - In fact, for this particular linear congruence, it would be
      quicker simply to keep trying the values 1, 2, 3, ... until
      you find a solution. 
    - We suggest you apply this direct method for solving
      a linear congruence whenever `n ≤ 13`.


### Linear congruences without solutions
    - Let `d` be the highest common factor of the integers `a`
      and `n`, where n > 1.
    - The linear congruence `ax ≡ b (mod n)` has _NO_ solutions if
      `b` is NOT divisible by `d`.


### Linear congruences with solutions
    - Let `d` be the highest common factor of the integers `a`
      and `n`, where `n > 1`.
    - The linear congruence `ax ≡ b (mod n)` _HAS_ solutions if
      `b` is divisible by `d`.
    - The solutions are given by the solutions of the equivalent
      linear congruence a d x ≡ b d  (mod n).



### Conics

    - `b` = positive y-intercept !!

        - if the focus is `(a, 0)`, then the directrix is `-a`

### Statics
    - we're trying to model situations where NOTHING is moving!
    - interesting point: if you just use Marks formula:
        - `F = |f|cosθ î + |f|sinθ ĵ`
        - then θ can be any angle (e.g. -110) and everything will
          just work out ok with the signs
    - for converting a component vector into its geometric form,
      use `tan^(-1) ĵ/î`

    - for all these, the net force acting is zero!
    - when drawning force diagrams, you might need ALTERNATE
      angle rules sometimes!
    - when answering the exam questions, put in your ASSUMPTIONS:
      eg point masses etc
    - You can only write the coefficient of static friction
      equation if the object is JUST ABOUT to move. (ie it's at
      the point of slipping). Then you can write `|F| = μ|N|`
