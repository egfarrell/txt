### "R-Module"
    - R = ring
    - Module = more general version of a vector space 
	- $MY_IMAGES/physics/what-are-tensors/basic-structure-of-R-module.jpg
    - Set 1: Group
    - Set 2: Ring
    - left module:  R x G -> G 
    - right module: G x R -> G 
    - main difference to vector space: the "bin" of scalars is
      just a `ring` and not a `field`

### "F-module" (aka Vector Space)
    - an `R` module can become a vector space
    - Set 1: a Group {} 
    - Set 2: a Field {}  (a commutative division ring)
    - there are proofs that only work for vector spaces that
      don't work for R-modules... 
    - Vector spaces can always be given a basis (either finite or
      infinite) 
        - but R-modules can only occasionally be given a basis
