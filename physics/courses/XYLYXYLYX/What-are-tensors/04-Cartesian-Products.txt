### Cartesian product
    - binary operation with a "big X"
    - it's a binary operation that takes a set on the left, a set
      on the right, and produces a set
      - ```
      - {set} X {set} = {set}
      - ```
    - It does so in a very specific way : it creates ordered
      pairs of combination: one element from the 1st set, one
      element from the 2nd
    - remember: vector spaces are sets aswell, so the cartesian
      product will work on them... 


### - Why is it useful?
    - well it gives us a bit of formal notation that allows us
      create other binary operations.
    - it allows me define binary operations as mappings from some
      set to another set
        - everything is a "map" in this type of maths
    - so the Cartesian product allows me to quickly define the
      domain of some binary operation (mapping)
    - I need the cartesian product to reflect all the possible
      ordered pairs
        - $MY_IMAGES/physics/what-are-tensors/using-the-cartesian-product.jpg
