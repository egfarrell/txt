- Mixtures:
    - Think of an ensemble.
    - Theres many many systems with a fraction `Pα` in
      a particular state `|α⟩`
    - Now consider the expectation value `<A>` of the ensemble.
      ('Expectation' value = average value)
    - It depends both on the mixture and the operator
      (observable) A.

    - `<A> = tr(ρA)`

### Trace of a density operator
    - `tr(ρ) = 1`

    - The density operator is a complete statistical description
      of results of experiments on the system.

    - The density operator of a pure state: all the probabilities
      are zero except for one which is one.

- Phase factors, Density operators
- you know |a⟩ ~ e^iθ|a⟩ ... kind of many state vectors for the same physical state
- well |a⟩ and e^iθ|a⟩ correspond to the same density operator, so a density operator gives a more one-to-one map to physical states in a way.

- Now many sub-ensembles of one big ensemble
- Mixture rule:     ρ1 with probability p1
                    ρ2 with probability p2

- Then we have ρ = p1ρ1 + p2ρ2 ....
                 = ∑(pα)(ρα)

- Different mixtures can have the same density operator:
- mixture 1: `1/2|z+⟩ + 1/2|Z-⟩`    equal likelyhood z-direction spin
- mixture 2: `1/2|X+⟩ + 1/2|X-⟩`    equal likelyhood x-component spin

    - both mixtures described by the same density operator!
    - both mixtures lead to the same ensemble averages in any experiment.
    - both mixtures statistically indistinguishable

- The entries along the diagonal of the density matrix are called the populations.

- So you can write any density operator what so ever as a sum of these basis operators.
- ρ = 1/2(11 + axX +ayY +azZ) - factor of 1/2 because the pauli basis is normalised to 2.
- ρ = 1/2(11 + a∙σ)           - where a is the 3-D REAL bloch vector (because ρ(dagger)=ρ)
